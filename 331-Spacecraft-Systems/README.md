## About This Course

This course introduces the fundamentals of spacecraft systems engineering —
how a spacecraft's subsystems (propulsion, attitude control, avionics,
telecom, power, mechanical, and thermal) are designed, integrated, and
tested to work together as a single functioning system. Concepts from this
course carry directly into **ASTE 421 - Mission Design** in the spring,
where students apply systems-level thinking to full mission architectures.
